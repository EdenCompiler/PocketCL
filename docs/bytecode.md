# Bytecode and image format

**Status: reserved.** The bytecode instruction set, operand encoding, calling convention, image sections, versioning, and malformed-image behavior are defined by M3 together with the VM and fasl loader. They are not specified in this M0 document, so no format should be inferred from this page.

When M3 implements the format, document the wire layout, compatibility/version policy, validation rules, and representative disassemblies here. Keep this page aligned with the loader and compiler and cover rejection of malformed images in tests.
